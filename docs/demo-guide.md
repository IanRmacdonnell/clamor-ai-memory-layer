# Clamor demo guide

Use the seeded synthetic community. Do not import private group chats during a portfolio demonstration.

## 60–90 second recording

1. Start in the busy community chat and name the problem: decisions disappear into scrollback.
2. Open the digest to surface decisions, blockers, resources, and tasks.
3. Ask, **What decisions were made about funding?** and point to the supporting source cards.
4. Ask an unsupported question to demonstrate abstention.
5. Close on permission filtering and the trust evaluation suite.

## Five-minute live interview demo

- Explain why retrieval permissions are applied before provider calls.
- Contrast the local analyzer with optional provider-backed summaries.
- Run `npm test` or `npm run eval` and discuss citation precision versus recall.
- Name the production tradeoff: JSON persistence keeps the prototype portable but is not a scalable datastore.

## Safe modification exercise

Practice adding a new operational signal, such as **needs owner**, to the local analyzer and its test fixture.
